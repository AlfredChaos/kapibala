# 需求拆解导读

本目录是对 [`docs/requirement.md`](../requirement.md)（AI 全栈岗位笔试题原文）的**无损拆分**：原文按「题目 → 契约 → 需求 → 场景 → 前端」线性铺开，规范细节散落各处，本拆解按**关注点**重组，便于通读与实现时查阅。

## 标注约定

- 未标注内容 = 原文规范的无损重组（结构化为表格/列表，语义不变）
- 【解读】= 分析推断，**非题目要求**，实现时可自行取舍
- 「原文 §x」= 来源锚点，有疑义时回原文核对
